# Top 50 Zero-INR Improvements (No-AI, Zero-Infra, Fire-and-Forget)

Strict constraints: zero INR spend, zero paid services, zero new infra, no AI features, no manual ops dependency.

1. Standardize typography scale with CSS variables and remove inline font sizes.
2. Unify button hierarchy (primary/secondary/ghost) across all pages.
3. Normalize hero layouts to a single reusable template.
4. Replace vague CTAs with outcome-based labels.
5. Add concise trust microcopy near profile and chat entry points.
6. Add helper text to all form inputs with format examples.
7. Add universal empty states with one primary action.
8. Ensure all inputs have visible labels (no label-only placeholders).
9. Normalize image sizes to prevent layout shift.
10. Trim redundant copy for faster scanability.
11. Introduce a strict 8px spacing scale across layouts.
12. Add consistent “data freshness” labels where relevant.
13. Normalize card borders, radii, and shadows to reduce visual noise.
14. Tighten nav labels to 1–2 words for quick scanning.
15. Add subtle section dividers in long pages.
16. Add a consistent back action in detail views.
17. Standardize table/list header typography.
18. Add preview-mode badge when data is mocked.
19. Normalize chip/tag semantics for status labels.
20. Add “why this match” snippets on cards (rule-based).
21. Add metric chips for top-level stats on listing pages.
22. Add a profile completion meter to profile and onboarding.
23. Add saved state labels to shortlist and interest actions.
24. Group form fields into 2-column grids on desktop.
25. Make all CTAs full-width on mobile.
26. Add focus-visible styling to all interactive elements.
27. Remove inline spacing styles and use shared classes.
28. Standardize admin table spacing and zebra striping.
29. Add confirmation prompts for destructive actions.
30. Create a reusable status banner component.
31. Add consistent progress indicator for onboarding steps.
32. Add privacy-first microcopy near contact visibility controls.
33. Ensure icons are decorative or properly labeled.
34. Replace “Open” with “View Profile” where clarity helps.
35. Add a consistent upgrade banner component for pricing gates.
36. Normalize grid/list toggles to one icon style and size.
37. Standardize “time ago” formatting across feeds.
38. Add single-line summary under chat headers.
39. Ensure error messages are actionable with next steps.
40. Standardize placeholder casing and examples in inputs.
41. Add uniform success state styling for submissions.
42. Align hero background gradients to one palette.
43. Limit chips/tags to top 2–3 per card to reduce clutter.
44. Introduce a compact secondary CTA style.
45. Set max line length for body copy to improve readability.
46. Normalize vertical spacing between sections across pages.
47. Unify copy tone: short, direct, benefit-focused.
48. Add skeleton loaders only for dense content sections.
49. Make cards clickable where it reduces missed interactions.
50. Create a minimal style guide section in CSS and apply it iteratively.
