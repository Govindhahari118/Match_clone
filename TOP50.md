# Top 50 Zero-INR, Zero-Infra, Zero-Maintenance ROI Improvements (No AI)

Strict constraints: zero INR spend, zero new infrastructure, zero ongoing maintenance. All items are one-time code/content updates. No AI features.

1. Standardize typography scale using CSS variables and apply across all headings, subheads, and body copy.
2. Normalize button hierarchy (primary/secondary/ghost) with consistent sizing and spacing across every page.
3. Align all page heroes to a single layout template with consistent label, title, copy, and CTA placement.
4. Replace vague CTAs with explicit outcome-based labels (e.g., “Browse Matches”, “Send Interest”).
5. Add concise trust and safety microcopy near profile and chat entry points.
6. Add input helper text for phone/OTP/profile forms to reduce abandonment.
7. Add universal empty-state patterns with clear next steps and one primary action.
8. Make all form labels explicit and visible to improve accessibility and reduce errors.
9. Ensure all images have descriptive alt text and consistent sizes for layout stability.
10. Trim page copy to remove redundant lines and increase scanability.
11. Introduce a consistent 8px-based spacing scale for layout rhythm and readability.
12. Add a consistent “last updated” or “data freshness” label where applicable for clarity.
13. Normalize card borders, shadows, and radii to reduce visual noise.
14. Tighten navigation labels to 1-2 words for faster scanning.
15. Add subtle section dividers to break long pages into digestible blocks.
16. Add a standard “back” action in detail views for easier navigation.
17. Ensure all list/table headers use consistent typography and letter spacing.
18. Add a consistent “preview mode” badge when data is demo or mocked.
19. Use consistent chip/tag color semantics for verified, premium, and status labels.
20. Add a concise “why this match” snippet on match cards to increase conversion.
21. Use consistent “metric chips” for top-level stats across listing pages.
22. Add a single-line profile completeness nudge on profile and onboarding steps.
23. Add “saved” state labels to shortlists and interest actions.
24. Reduce form field count per screen by grouping related inputs into two-column grids.
25. Ensure CTA buttons are full-width on mobile for thumb reach.
26. Add keyboard focus-visible styling to all interactive elements.
27. Remove inline font sizes in JSX and use shared classes instead.
28. Normalize table row spacing and zebra-striping for admin views.
29. Add consistent confirmation to destructive actions (remove/report/decline).
30. Create a single “status banner” component for notifications and system messages.
31. Add consistent “progress” indicator for onboarding and verification flows.
32. Add “privacy first” microcopy near contact/phone visibility sections.
33. Ensure icons are purely decorative or labeled for screen readers.
34. Replace ambiguous labels like “Open” with “View Profile” where clarity helps.
35. Add a consistent “upgrade” banner style used in viewer and pricing surfaces.
36. Normalize list and grid view toggles to a single icon style and size.
37. Add “time ago” formatting consistency (minutes/hours/days) across feeds.
38. Add a single-line summary under chat headers to set expectations.
39. Ensure error messages are actionable and mention the next step.
40. Use consistent input placeholder casing and examples (e.g., city, phone format).
41. Add a uniform “success” state style for submissions and actions.
42. Align all hero background gradients to the same palette for brand cohesion.
43. Remove visual clutter by limiting chips/tags to the top 2-3 most important.
44. Introduce a compact “secondary CTA” style for low-priority actions.
45. Set max line-length for long paragraphs to improve readability.
46. Add consistent spacing between sections across all pages.
47. Unify the copy tone: short, decisive, benefit-focused sentences.
48. Add “loading” skeletons only where content density is high to reduce perceived wait time.
49. Ensure all cards are clickable where it makes sense, to reduce missed interactions.
50. Create a small style guide section in CSS with reusable utility classes and apply steadily.
