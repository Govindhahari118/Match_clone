# Matree

Production-oriented native **Kotlin + Jetpack Compose** Android matrimony app backed by Firebase.

Repository CI certifies code-controlled gates only. Production promotion additionally requires exact-SHA operator evidence for Firebase/Play configuration, signing, App Check, real-device acceptance, security, accessibility, performance, legal/Data Safety, rollout, monitoring, and rollback.
