## 8. Membership & Monetisation Models

### 8.1 Freemium Model (Most Common)

**Free Tier typically includes:**
- Create profile
- Browse profiles
- Send express interest
- Receive interests
- Basic search filters

**Paid Tier typically unlocks:**
- View contact details (phone/email)
- Send personalized messages / chat
- Advanced search filters
- Profile highlight / boost
- Daily/weekly curated matches

### 8.2 Membership Plan Examples

#### MatrimonialsIndia
| Plan | Price | Duration | Key Benefits |
|------|-------|----------|-------------|
| Free | ₹0 | 0 days | Browse, Send interest |
| Silver | ₹599 | 10 days | 20 contacts, 50 messages |
| Gold | ₹1,500 | 3 months | 150 contacts, unlimited messages |

#### Shaadi.com
- Free: Create profile, browse, send interests
- Premium (multiple tiers): Chat, video call, advanced filters, priority support, profile boost
- **30-day money-back guarantee** if no match found

#### LoveVivah
- Free: Search and browse
- Premium: View contacts, send emails, chat
- **18-month match guarantee or 100% money back**

#### MatchFinder
- Starting from ₹100 (lowest in market)
- Add-ons: Horoscope generation, profile highlighting, phone top-ups

#### Vivaah
- **100% completely free** — no charges at all
- All features free: Contact viewing, messaging, photo album

#### Corishta
- **100% forever free** — No hidden subscriptions

#### SecondSutra
- Free to register and browse
- **₹500 per Virtual Meet credit** (ensures seriousness)
- Relationship Manager support included in RM-assisted plans

### 8.3 Subscription Durations (Common)
- 1 month / 3 months / 6 months / 12 months
